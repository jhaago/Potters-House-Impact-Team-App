# Offline Tracking Field-Test Overview

Use the [Android offline tracking field test](android-offline-tracking-field-test.md) for the executable two-phone, forced-relay, and 5–10-phone procedures.

Record each run in the [results template](android-offline-tracking-results-template.md) and update the [device capability matrix](device-capability-matrix.md) only from physical evidence. Do not commit participant names or precise coordinates.

The Android results are not evidence of iPhone background reliability. Native iPhone adapters and real-device mixed-platform testing remain the next platform gate.
